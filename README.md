# Sonic Regen

A fan-made homage that combines the Mega Drive Sonic trilogy (Sonic 1, Sonic 2 and Sonic 3 & Knuckles) into one browser game. It plays one zone inspired by each game, with Sonic, Tails and Knuckles, a Blue Sphere-style special stage, Chaos Emeralds and Super forms.

> **Fan project — not affiliated with or endorsed by SEGA.** Sonic the Hedgehog and related characters are trademarks of SEGA. This repository contains **no SEGA assets**: every sprite, tile, background, sound effect and piece of music is original and generated by code. Zones are homages with original layouts, not copies of the classic maps.

## Play

```bash
npm install
npm run dev        # open the printed URL
```

To build a static site in `dist/` that you can host anywhere, run `npm run build`.

### Controls

| Action                       | Keyboard                      | Gamepad            |
| ---------------------------- | ----------------------------- | ------------------ |
| Move / look up / crouch      | Arrow keys or WASD            | D-pad / left stick |
| Jump (A / B / C)             | Z, X, C, Space (also J, K, L) | A, B, X/Y          |
| Start / pause                | Enter                         | Start              |
| Debug overlay                | F1 or \`                      | —                  |
| Pause / step a frame (debug) | F2 / F3                       | —                  |

Keys can be rebound under **Options**.

**Moves:**

- **Everyone:** run, roll (Down while moving), spindash (hold Down, tap Jump, release Down), and jump.
- **Sonic:** the insta-shield (Jump again in mid-air). With an elemental shield, the same button does a fire dash, a bubble bounce or a lightning double jump.
- **Tails:** flies or swims when you press Jump again in mid-air; tap Jump to climb, and he tires after 8 seconds.
- **Sonic & Tails:** hold Up and jump next to Tails to be carried. Hold Up to climb, and press Jump to let go.
- **Knuckles:** glides when you press Jump again in mid-air (hold it to keep gliding). He grabs walls, climbs with Up/Down, and breaks cracked walls.
- **Super form:** collect all 7 Chaos Emeralds, have 50 rings, then press Jump again in mid-air.

### Content (milestone 1)

| Zone              | Homage to   | Highlights                                                                                                         |
| ----------------- | ----------- | ------------------------------------------------------------------------------------------------------------------ |
| **Palm Coast**    | Sonic 1     | Checkered hills, loops, log bridge over the sea, swinging platforms, collapsing ledges, wrecking-ball boss         |
| **Neon Refinery** | Sonic 2     | Transport tubes, speed boosters, split upper and lower routes, rising pink chemical, chemical-dropper boss         |
| **Jungle Isle**   | Sonic 3 & K | Ziplines, Knuckles-only ledges and a secret cave, the jungle fire-bombed mid-act, flooded ruins, flame-bomber boss |

Hidden giant rings lead to seven Blue Sphere-style special stages, one for each Chaos Emerald. Progress is saved to three slots in your browser's local storage.

### Handy URLs for testing

- `?zone=neon-refinery&act=2&team=knuckles` starts an act directly. The team can be `sonic+tails`, `sonic`, `tails` or `knuckles`.
- `?special=3` opens special stage 4.
- `?debug` turns on the sensor and hitbox overlay. `?mute` disables audio.
- `?zone=test` opens the physics test room.

## Development

```bash
npm test           # unit, act and full playthrough tests (Vitest)
npm run test:e2e   # builds, then boots the game in Chromium (Playwright)
npm run lint       # ESLint + Prettier
npm run typecheck
```

CI runs all of the above on every push.

### How it works

| Area               | Where                                              | Notes                                                                                                                                                                                                                           |
| ------------------ | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Physics            | `src/player/Player.ts`, `src/physics/`             | Follows the Sonic Physics Guide's documentation of the Mega Drive games: ground speed and angle, A–F sensors in four modes, slope factors, control lock, the landing-angle speed conversion, air drag, spindash and water.      |
| Collision          | `src/level/collision.ts`                           | Levels are a per-pixel collision map with two loop paths (A and B) and top-only pixels, stored in sparse 64×64 chunks. Sensors measure surface angles by fitting a line through nearby probes, so any curve gets smooth angles. |
| Level building     | `src/level/builder.ts`                             | Levels are written as code: `terrain()` profiles, `loop()`, `quarterPipe()`, `ceiling()`, `rect()`/`poly()`, `carveAbove()` for tunnels, and `place()`/`onGround()` for objects.                                                |
| Terrain art        | `src/level/terrain-render.ts`                      | Painted per pixel by the zone theme from material IDs and the distance to the surface, so it always matches the collision.                                                                                                      |
| Characters and art | `src/art/`                                         | Characters are posed "puppets" rasterised without anti-aliasing. All other sprites are procedural.                                                                                                                              |
| Audio              | `src/audio/`                                       | A Web Audio synth with pulse, triangle and FM voices plus drums, playing original songs written in MML (`songs.ts`).                                                                                                            |
| Special stage      | `src/specialstage/`, `src/scenes/special-stage.ts` | The floor is a per-pixel raycast onto a curved globe.                                                                                                                                                                           |

### Adding a zone

1. Create `src/zones/<name>/` with:
   - a `theme.ts` (a `ZoneTheme` with `paint()` and `drawBackground()`)
   - an `acts.ts` that builds each act with `LevelBuilder`
   - any zone-specific objects and the boss, registered with `registerObject()`
2. Export a `ZoneDef` from `index.ts` and add it to `ZONES` in `src/zones/all.ts`.
3. Run `npm test`. The zone tests check that every act builds with known objects and that its boss sequence works. The playthrough test checks that each act can be finished.
